# H2N4 Parity Checklist

This project borrows useful analysis patterns from mature poker trackers while deliberately avoiding a full product clone.

## In scope for MVP inspiration

- Reports grouped by player, position, line, and spot feature.
- Custom-filter-like queries over structured hand and decision features.
- Dark professional analysis layout.
- Issue-oriented review workflow.
- Representative hands attached to repeated patterns.
- Reliability warnings for small or concentrated samples.

## Out of scope

- Real-time HUD.
- Live table overlays.
- Screen capture or OCR.
- Reading a running poker client.
- Shared population or opponent database.
- Full H2N4 filter builder.
- Full hand replayer.
- Solver integration.
- Commercial interface replication.
- Brand, icon, wording, or visual copying.

## MVP parity rule

For each H2N4-like idea, implement only the minimum version that supports the personal training loop:

`import -> normalize -> report -> mine spots -> create issue cards -> review -> study -> next cycle`

## Design guardrail

The UI may use a dark, dense, professional analytics style. It must not copy Hand2Note branding, icons, exact wording, or commercial interface details.
