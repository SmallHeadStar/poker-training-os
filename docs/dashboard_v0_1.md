# Dashboard v0.1

## Purpose

The first Streamlit dashboard is a compact review surface for after-session training. It is not a live HUD and must not imply live advice.

Every displayed analytical value must be treated as provisional unless its source metric is marked `h2n4_validated` in the parity registry.

## Layout

- Dark background.
- Left navigation.
- Top session filter.
- KPI cards.
- Report tables.
- Loss map.
- Drillable issue cards.
- Review queue table.
- Source badges.
- Reliability badges.

## Pages or areas

1. Session Summary
2. Basic Reports
3. Loss Map
4. Issue Cards
5. Review Queue / Training Focus

## Visual guardrails

- Use a restrained professional analysis style.
- Avoid flashy animation.
- Avoid cyberpunk decoration.
- Avoid financial-control-room styling.
- Do not copy Hand2Note branding, icons, exact wording, or commercial interface details.

## Empty states

Until the parser and reports exist, dashboard surfaces should show honest empty states that point to the expected artifact rather than inventing sample results.
